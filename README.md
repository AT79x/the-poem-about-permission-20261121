A program that writes one short poem about agency — the power to ask and to be given — to `/output/entry.txt`. Pure Python 3 standard library, deterministic, no network. The poem is the `POEM` constant at the top of `main.py` ("Borrowed Hands", 208 characters, 6 lines).

## Run it

```sh
python3 main.py
```

Writes `entry.txt` to `$MAKEFUN_OUTPUT_DIR` (default `/output`).
